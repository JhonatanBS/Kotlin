<h1 align="center">Single Number</h1>

<p>
Given a <strong>non-empty</strong> array of integers <code>nums</code>, every element appears <em>twice</em> except for one. Find that single one.
</p>

<p>
You must <strong>implement a solution with a linear runtime complexity and use only constant extra space.</strong>
</p>

<h2>Example 1:</h2>

<p>
<strong>Input:</strong> nums = [2,2,1]<br>
<strong>Output:</strong> 1
</p>

<h2>Example 2:</h2>

<p>
<strong>Input:</strong> nums = [4,1,2,1,2]<br>
<strong>Output:</strong> 4
</p>

<h2>Example 3:</h2>

<p>
<strong>Input:</strong> nums = [1]<br>
<strong>Output:</strong> 1
</p>
